邮件转发助手 1.0.10
====================

一、运行条件
1. Windows 10 1607 或更高版本，32 位和 64 位均可。
2. 将整个文件夹复制到本机固定、可写的位置，请勿只复制 EXE。
3. 双击“邮件转发助手.exe”即可运行，无需安装、无需管理员权限。

二、首次使用
1. 打开“邮箱设置”，填写 IMAP 或 POP3 收信配置以及 SMTP 发信配置。
2. 分别使用“测试收信连接”和“发送测试邮件”验证配置。
3. 新增至少一条转发规则。可只按标题关键字匹配，也可填写发件人邮箱，与标题关键字联合匹配。
4. 粘贴收件人地址后会即时显示去重人数；保存时自动去重，且不允许填写本邮箱地址。
5. 点击“启动监测”。第一次连接只记录当前邮箱基线，不会转发历史邮件。
6. IMAP 规则可勾选“只转发未读邮件”；检查时已读的邮件会记录为跳过，不再补转发。
7. 邮箱设置可启用“所有匹配规则处理完成后，将原邮件设为已读”；任一规则失败或待确认时，原邮件保持未读。

三、日常使用
1. 主界面菜单栏右侧可切换“简体中文”或“繁體中文”，选择会自动保存并立即应用到各窗口、托盘菜单和提示信息。
2. 关闭主窗口后程序仍驻留托盘；请从托盘菜单选择“退出”以完全关闭。
3. 暂停期间收到的邮件会在恢复后继续处理。
4. 若发送结果不明确，日志显示“待人工确认”，程序不会自动重发。
5. 可在日志详情中确认已送达，或确认重新发送；重新发送可能产生重复邮件。
6. “运行状态”页显示本次程序启动后当天的监测次数、转发成功数和转发失败数。

四、数据与迁移
1. 所有配置、日志和去重状态保存在程序旁的 Data 文件夹。
2. 密码由当前 Windows 用户加密；更换电脑或 Windows 账户后需重新输入密码。
3. 更新程序时先退出，保留 Data 文件夹，再替换其他程序文件。
4. 删除程序前请先在邮箱设置中关闭“随 Windows 启动”。

五、注意事项
1. POP3 服务器必须支持 UIDL，否则程序会拒绝启动监测。
2. 程序以只读方式访问邮箱，不会标记已读、移动或删除原邮件。
3. “允许不受信任证书”会降低安全性，仅应在确认内网邮件服务器证书可信时启用。
4. 为防止自动转发死循环，规则收件人不能包含“发件人邮箱”或可识别为邮箱地址的收信用户名。
