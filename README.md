# 邮件转发助手

面向 Windows 10 内网邮箱环境的绿色版邮件监测与自动转发工具。程序定时检查一个 IMAP 或 POP3 邮箱，并根据多条业务规则，通过 SMTP 转发原邮件正文、内嵌图片和附件。

当前版本：`v1.0.10`

## 主要功能

- 支持 IMAP、POP3 和 SMTP，可配置无加密、SSL 直连、STARTTLS 或自动协商。
- 一个邮箱账户可配置多条独立转发规则。
- 支持发件人地址与标题关键字联合匹配。
- 标题关键字按“不区分大小写、包含任意一个”判断。
- 支持一对一和一对多转发，保留纯文本、HTML、内嵌图片及附件。
- 收件人地址自动校验、去重，并禁止转发到本邮箱地址。
- IMAP 规则可独立选择“只转发未读邮件”。
- IMAP 可全局设置“所有匹配规则处理完成后，将原邮件设为已读”。
- 按“邮件 + 规则”永久去重，避免重复转发。
- 支持托盘驻留、随当前 Windows 用户登录后启动、自动监测和状态通知。
- 支持简体中文与繁体中文界面。
- 支持日志筛选、详情查看、CSV 导出以及发送结果不明确时的人工确认。

## 运行环境

- Windows 10 1607 或更高版本，32 位和 64 位均可。
- .NET Framework 4.6.2 兼容运行环境。
- 能够访问配置的内网邮箱服务器。
- 程序目录必须可写，以便保存本地数据和日志。

## 从源码构建

开发环境需要安装 .NET SDK。项目使用 C# WinForms、.NET Framework 4.6.2、MailKit、MimeKit 和 LiteDB。

```powershell
.\build.ps1
```

构建脚本会先执行自动化测试，再在 `artifacts` 目录生成绿色版文件夹和 ZIP 压缩包。

## 项目结构

```text
src/MailForwarderAssistant/        主程序源码
tests/MailForwarderAssistant.Tests/ 自动化测试
MailForwarderAssistant.sln         解决方案文件
build.ps1                          测试与发布脚本
使用说明.txt                       随程序发布的简要说明
```

## 本地数据与安全

程序运行后会在自身目录的 `Data` 文件夹保存设置、规则、日志、监测游标和去重记录。邮箱密码使用 Windows DPAPI 按当前 Windows 用户加密。

`Data`、数据库、编译输出和发布包均已加入 `.gitignore`，不得提交到版本库。将程序复制到其他电脑或切换 Windows 账户后，需要重新输入邮箱密码。

## 升级发布

1. 更新项目版本号及说明文档。
2. 执行 `build.ps1`，确保全部测试通过。
3. 检查生成的绿色版程序。
4. 提交源码变更并创建对应版本标签。
5. 发布时只分发构建生成的 ZIP；升级现有安装时保留用户的 `Data` 文件夹。

## 使用注意

- POP3 服务器必须支持 UIDL，否则程序会拒绝启动监测。
- 忽略服务器证书错误会降低安全性，只应在邮箱管理员确认内网证书可信时启用。
- 多个转发收件人统一位于 `To`，彼此可以看到其他收件人的地址。
- 当前“随 Windows 启动”在用户登录 Windows 后触发，不能在欢迎界面尚未登录时运行。
